# Savoir-pour-sauver-
Créer un site « SAVOIR POUR SAUVER », bibliothèque numérique scientifique. Inscription et connexion obligatoires pour télécharger les PDF. Catégories : soins infirmiers, santé publique, recherche et formation. Prévoir un espace administrateur sécurisé pour ajouter, modifier et supprimer les documents, avec recherche et interface mobile.
